# 📚 Mais Literatura!  
### Descubra autores brasileiros com busca inteligente — Projeto da Imersão Dev com IA (Alura + Google Gemini)

Bem-vindo(a) ao **Mais Literatura!**, um projeto criado durante a *Imersão Dev com IA*, com o objetivo de aproximar leitores(as) da rica literatura brasileira.  
Aqui você pode pesquisar autores, conhecer suas obras e visualizar informações rapidamente através de uma interface simples e intuitiva.

---

## ✨ Sobre o Projeto

Este é um projeto front-end desenvolvido com:

- **HTML** para estrutura  
- **CSS** para estilo  
- **JavaScript** para lógica  
- **IA generativa (Google Gemini)** como apoio no desenvolvimento  

A aplicação permite pesquisar escritores brasileiros, retornando informações como biografia, estilo literário e lista de obras.

---

## 🚀 Funcionalidades

- 🔍 **Busca dinâmica** por autores brasileiros  
- 📘 Exibição de obras e curiosidades  
- 🧠 Dados estruturados em JSON  
- 📱 Layout simples e amigável  
- ⚡ Carregamento rápido  

---

## 🛠️ Tecnologias Utilizadas
